⚡ BANANAWOW не спит

Бесплатный Render засыпает ~через 15 минут без визитов. Внутренний таймер в боте не помогает — он тоже спит. Нужен внешний пинг каждые 5 минут на URL ниже.

Пинг-URL (скопируй):
https://YOUR-SERVICE.onrender.com/api/ping Проверить сейчас

0. Cloudflare Worker — «второй сайт» который не спит

Бесплатный Worker на Cloudflare не засыпает как Render. Раз в 5 минут он пингует бота. Код: scripts/cloudflare-ping-worker.js

  1. dash.cloudflare.com → регистрация
  2. Workers & Pages → Create → Create Worker
  3. Вставь код из cloudflare-ping-worker.js (подставь свой URL) → Deploy
  4. Triggers → Cron Triggers → */5 * * * * (каждые 5 мин)
Открыть Cloudflare

1. UptimeRobot — самый простой

Бесплатно, пинг раз в 5 минут.

  1. Открой uptimerobot.com
  2. Add New Monitor
  3. Type: HTTP(s)
  4. Name: BANANAWOW
  5. URL: вставь пинг-URL выше
  6. Interval: Every 5 minutes
  7. Create Monitor
Открыть UptimeRobot

2. cron-job.org

  1. Регистрация
  2. Create cronjob → URL = пинг выше
  3. Every 5 minutes

Проверка

  1. Настрой UptimeRobot или Cloudflare
  2. Не открывай бота 25–30 минут
  3. В Telegram → /start → Play должен открыться сразу
  4. Статус: /api/health — смотри last_external_ping_sec_ago
