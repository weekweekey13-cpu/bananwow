BANANAWOW 24/7 (как Калаграм)

Та же схема: GitHub + Render + пинг, чтобы free-сервер не засыпал. Компьютер можно выключать.

Шаг 1 — GitHub

  1. Регистрация (можно через Google)
  2. New repository → имя: bananawow → Create (без README)
  3. Скопируйте URL: github.com/ВАШ_НИК/bananawow
1. GitHub signup 2. Создать репозиторий bananawow

Шаг 2 — Загрузить код

  1. Дважды клик ЗАГРУЗИТЬ НА GITHUB.bat в папке «тгбот»
  2. Вставьте URL репозитория
  3. Если спросит пароль — Personal Access Token (галочка repo)

Шаг 3 — Render

  1. Регистрация (через GitHub удобнее)
  2. New + → Web Service → репо bananawow
  3. Build: pip install -r requirements.txt
    Start: python bot.py
    Plan: Free
  4. Environment: BOT_TOKEN = токен от @BotFather
  5. Create → 3–5 мин → ссылка https://….onrender.com
3. Render signup 4. Создать Web Service

Шаг 4 — Keep-alive (не спать)

Как у Калаграма: UptimeRobot пингует /api/ping каждые 5 минут.

  1. Запусти НАСТРОЙ KEEP-ALIVE.bat
  2. Или открой https://ВАШ.onrender.com/keepalive-setup
UptimeRobot

Готово

Telegram → бот → /start → Play. ПК можно выключить.
